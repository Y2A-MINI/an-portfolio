Case 02

Dr.SHIN

靴の写真をAIで診断し、状態レベルと推奨ケア商品を提示するWebアプリ。Shopifyの公開ページ上で稼働しています。

Status
本番稼働
Scope
UI/UX / Figma / Frontend / AI連携
Stack
Shopify / Fly.io / Claude API

Figma

診断前にサービスの内容と使い方が伝わるよう、説明から診断開始までを縦型の一画面に整理しています。

Live product

テスト画像の選択からAI診断、推奨商品、結果画面下部までの操作を収録しています。

実装・検証事実

  1. 01Shopifyの公開ページで診断フローが稼働
  2. 02実画像をClaude APIで解析し、状態を提示
  3. 03診断結果から関連商品へつながる導線を実装

掲載動画は2026年9月4日に、公開ページ上でテスト用画像を使って収録した動作確認です。

AN担当範囲

体験設計、Figma UI v3の調整、実装要件策定・レビュー、本番デプロイ、実ブラウザ検証を担当。
